> 此材料属于 environment/，不包含源码、补丁或临时脚本。代码仍留在适配容器的插件仓库。

## 最终 diff 自检

- [ ] 符合现有职责/dispatch 设计，共享层未依赖单个模型路径、服务名或厂商 SDK
- [ ] 已覆盖守卫命中和未命中、适用的导入/注册/数值/graph/共享调用方回归
- [ ] 未通过吞异常、空实现、扩大 skip/xfail 或无依据放宽容差掩盖问题
- [ ] 未混入临时脚本、复制测试套件、原始日志、机器路径、预编译环境快照或无关重构
- [ ] 已单独说明 inherited diff、本任务差异及不可合并的内容；未擅自处理他人改动
- [ ] 审查结论对应当前 HEAD 与 dirty diff，变更后失效部分已重审

- PR 问题与行为说明、设计理由、测试和限制：
- 建议的 PR 范围或拆分及依赖：
- 完整适配验收状态（与设计审查结论分开）：
