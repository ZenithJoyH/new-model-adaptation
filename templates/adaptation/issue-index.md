# 适配问题索引

本目录只记录当前模型在当前平台适配过程中实际遇到的问题、诊断过程、解决方法与
验证结论。除 `README.md` 外，每个实质性问题使用一个编号 Markdown 文件，例如
`001-graph-capture-failure.md`。

不得在本目录存放脚本、配置、源码、补丁、测试文件、原始日志、JSON/YAML、临时输出
或制品副本。Plugin 仓库只保存必要的产品实现和可长期维护的回归测试；一次性过程脚本
和代码放在适配容器内、各源码仓库之外的独立临时工作目录，且不得提交。FlagGems 复现
统一保留在已批准工作根目录的 `07-bugs/` 并通过已核实的容器对应路径原地执行；已有用例不得
再复制到 `/bug/`。仅在必要工具明确要求时，才使用指向同一目录的已批准映射或明确例外。
本目录通过准确路径、revision/commit、命令和结果进行引用。

新问题请复制仓库模板 `templates/adaptation/issue-record.md`，按出现顺序分配三位编号。
