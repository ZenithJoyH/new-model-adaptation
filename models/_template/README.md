`scripts/adapt-model` 创建阶段目录和文件，不提前生成未请求平台的环境分析。

| PPU | `not_started` | - | - | - |
| MetaX | `not_started` | - | - | - |
| Ascend | `not_started` | - | - | - |
| Moore Threads | `not_started` | - | - | - |
