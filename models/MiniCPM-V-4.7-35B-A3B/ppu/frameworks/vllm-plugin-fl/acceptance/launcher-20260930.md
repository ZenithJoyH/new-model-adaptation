## 最小服务配置的理由

- `CUDA_VISIBLE_DEVICES=0,1` 与 TP2 固定已核实的资源拓扑；权重路径只读。
- `--trust-remote-code` 用于该权重自带配置/处理器，`--served-model-name`
  固定服务身份，`--max-model-len 50000`、`--max-num-seqs 8` 固定已验证的
  内存预算与并发上限。
- `--mm-processor-cache-gb 0` 保留 canvas 尺寸元数据正确性；视觉
  `TORCH_SDPA`、`data` 模式和现有 Plugin 修正是已核实的 PPU TP2 视觉路径。
- `--enable-prefix-caching` 明确开启非性能服务的缓存；该 vLLM 安装在参数
  缺省时曾实测为关闭。
- `--compilation-config '{"mode":3,"cudagraph_mode":"FULL_AND_PIECEWISE"}'`
  是用户指定的图模式；安装的 vLLM 0.24.0 把它定义为 decode full 图、
  prefill/混合批次 piecewise 图，后者要求 `VLLM_COMPILE`（mode 3）。
- `--host 127.0.0.1 --port 8016` 保持本任务 API 地址；脚本先尝试绑定该
  地址，端口已占用时拒绝启动。已在旧服务占用端口时实测返回
  `OSError: [Errno 98] Address already in use`，没有覆盖旧服务。
- `HF_HOME`、`XDG_CACHE_HOME`、Triton/Torch 扩展/Inductor/vLLM 缓存、
  FlagGems SQLite 和 `TMPDIR` 全部定位于批准根下 `06-cache/` 与 `05-tmp/`；
  `PYTHONDONTWRITEBYTECODE=1` 避免源码目录内隐式写入。日志逐次生成唯一文件，
  置于 `04-runs/start-model/`，避免覆盖历史运行。
