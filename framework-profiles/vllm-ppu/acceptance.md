# 平头哥原生 vLLM 验证边界

- 已声明的服务验证复用最小根级 `start-model.sh` 的默认启动，删除非必要缓存目录环境变量。
  若以后补齐并获准精度/性能验收，遵循[统一服务启动入口](../../docs/remote-operations.zh-CN.md#统一服务启动入口)：
  同一脚本默认开启前缀缓存，仅显式性能开关关闭；本条不扩展当前 experimental 验收能力。
- execution-mode：真实模型在 eager 与 graph 推理，覆盖文本、图像及模型声明的视频路径；
  检查预填充/解码、视觉 token 与位置、权重映射、批处理，保留实际图模式及变输入回放证据。
- sanity：已验证图服务上的冻结并发与参考输出的小集合，检查每个响应、错误、超时和输出健康。
  该集合不是正式数据集精度评测，也不能代替性能基线。
- evidence：记录实际安装文件、版本/来源、修改前后 SHA 或 Git diff、已有改动、服务身份，
  明确其他平台、共享调用方与未执行项。没有 Git 时不伪造 revision。
- summary：验证批准根的最小 start-model.sh、权限、语法、实际启动、工作根映射、必要参数、
  正常前缀缓存及容器内部交付副本；只报告已执行的镜像验证。

所有非性能验证开启前缀缓存。以后若用户明确选择性能工作，必须先补齐正式精度与性能
原生接口及门禁；仅知道 `--no-enable-prefix-caching` 参数不构成可用的正式性能能力。
当前 experimental 状态允许上述声明的验证，不能完成完整正式验收或达到 optimized。
